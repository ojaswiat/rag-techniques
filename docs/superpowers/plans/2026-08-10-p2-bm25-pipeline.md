# P2 BM25 Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement P2, the purely statistical BM25 retrieval pipeline (`rank_bm25`'s `BM25Okapi`, custom tokenizer, one pickle per document), conforming to the shared `Retriever` ABC used by P1/P3.

**Architecture:** P2 skips the LlamaIndex/embedding stack entirely. `build_bm25_index.py` reads raw node rows from `database_manager.get_nodes_by_document()`, tokenizes each node's `content` with a custom regex tokenizer, and pickles `{"node_ids": [...], "bm25": BM25Okapi(...)}` per `document_id` under `storage/bm25/`. `p2_bm25.py`'s `P2BM25Retriever` loads that pickle, tokenizes the query with the exact same tokenizer function, ranks by `bm25.get_scores()`, and re-fetches node content for the winning ids from `database_manager` to build `NodeWithScore` results.

**Tech Stack:** Python, `rank_bm25` (`BM25Okapi`), `aiosqlite` via `database_manager`, `pytest` + `pytest-asyncio` (repo has `asyncio_mode = "auto"`), `uv` package manager. All work happens inside `project/`.

## Global Constraints

- Library is `rank_bm25`'s `BM25Okapi` class only — never LlamaIndex's `KeywordTableIndex` (it calls an LLM).
- Zero LLM calls anywhere in this pipeline's build or retrieval path.
- Tokenizer must be the **literal same callable** at index time and query time — one function (`pipelines.bm25.tokenizer.tokenize`), both call sites.
- Tokenizer rules: preserves numbers, decimals, `%`, and currency symbols attached to numbers; strips table-markdown pipes (`|`) but keeps cell values; no stemming.
- Storage: `storage/bm25/<document_id>.pkl`, one pickle per document (per this spec's logged deviation decision), atomic write via temp file + `os.rename`.
- Resumability: skip-if-already-built at document granularity, matching `build_vector_index.py`'s `is_document_indexed` pattern.
- Empty corpus (`get_nodes_by_document` returns `[]`) must raise `ValueError`, not silently no-op.
- `retrieve()` must filter to `document_id` internally (required scoping, not a banned pre-filter) and must raise a clear error (not return `[]`) when the document's index was never built.
- Every loop script needs a hardcoded `LOCAL_TEST_THROTTLE` boolean via the existing `loop_template.apply_throttle()` helper — already implements this; just call `loop_template.apply_throttle(manifest)` in `main()`.
- No dev-history, "Doubt" tags, fix narratives, or agentic-session references in code/test comments or docstrings.
- Package manager is `uv`; run everything from inside `project/`.
- Never commit or push without an explicit ask in that turn, even mid-task-sequence.

```python
"""Custom BM25 tokenizer (Project Idea.md §6): preserves numbers, decimals,
percentages and currency amounts; strips table-markdown pipes; applies no
stemming. Called identically at index time (build_bm25_index.py) and
query time (p2_bm25.py) -- one function, both call sites, so scores are
never computed against mismatched vocabularies.
"""
import re

_TOKEN_PATTERN = re.compile(r"[$£€]?\d+(?:,\d{3})*(?:\.\d+)?%?|[A-Za-z]+")


def tokenize(text: str) -> list[str]:
    text = text.replace("|", " ")
    return [token.lower() for token in _TOKEN_PATTERN.findall(text)]
```

```python
"""Builds the per-document P2 BM25 index (Phase 5) -- one pickled
BM25Okapi corpus per filing under storage/bm25/.

Purely statistical: rank_bm25.BM25Okapi over the shared tokenizer, no
embeddings, no LLM call, per Guardrails.md's "Retrieval/indexing runs
locally" rule. Resumable at document granularity, matching
build_vector_index.py's skip-if-already-built pattern.
"""
import asyncio
import json
import os
import pickle
from pathlib import Path

from rank_bm25 import BM25Okapi

import database_manager as dbm
import loop_template
from pipelines.bm25.tokenizer import tokenize

STORAGE_ROOT = Path("storage/bm25")
DB_PATH = "benchmark.db"
MANIFEST_PATH = "data/filings_manifest.json"


def _index_path(document_id: str, storage_root: Path) -> Path:
    return storage_root / f"{document_id}.pkl"


def is_document_indexed(document_id: str, storage_root: Path | None = None) -> bool:
    if storage_root is None:
        storage_root = STORAGE_ROOT
    return _index_path(document_id, storage_root).exists()


async def build_index_for_document(
    document_id: str,
    db_path: str = DB_PATH,
    storage_root: Path | None = None,
) -> dict:
    if storage_root is None:
        storage_root = STORAGE_ROOT

    if is_document_indexed(document_id, storage_root=storage_root):
        return {"document_id": document_id, "skipped": True, "node_count": 0}

    nodes = await dbm.get_nodes_by_document(db_path, document_id)
    if not nodes:
        raise ValueError(
            f"No nodes found for document_id={document_id!r}. Run Phase 2 "
            "ingestion for this filing before building the BM25 index."
        )

    tokenized_corpus = [tokenize(node["content"]) for node in nodes]
    bm25 = BM25Okapi(tokenized_corpus)
    payload = {"node_ids": [node["node_id"] for node in nodes], "bm25": bm25}

    storage_root.mkdir(parents=True, exist_ok=True)
    final_path = _index_path(document_id, storage_root)
    temp_path = storage_root / f"{document_id}.pkl.tmp"
    with open(temp_path, "wb") as f:
        pickle.dump(payload, f)
    os.rename(temp_path, final_path)

    return {"document_id": document_id, "skipped": False, "node_count": len(nodes)}


async def main():
    STORAGE_ROOT.mkdir(parents=True, exist_ok=True)
    with open(MANIFEST_PATH) as f:
        manifest = json.load(f)
    manifest = loop_template.apply_throttle(manifest)

    for entry in manifest:
        document_id = entry["document_id"]
        result = await build_index_for_document(document_id)
        status = "skipped (cached)" if result["skipped"] else f"indexed ({result['node_count']} nodes)"
        print(f"{document_id}: {status}")


if __name__ == "__main__":
    asyncio.run(main())
```

```python
"""P2: BM25 statistical retrieval (Architecture.md §6 Phase 5).

Loads the per-document pickled BM25Okapi corpus built by
build_bm25_index.py, tokenizes the query with the exact same tokenizer
used at index time, and ranks by BM25 score. No embeddings, no LLM call
anywhere in this class -- node content comes straight from
database_manager rather than through the LlamaIndex node-conversion
machinery P1/P3 use, keeping P2 a genuinely raw statistical baseline.
"""
import asyncio
import pickle
from pathlib import Path

from llama_index.core.schema import NodeWithScore, TextNode

import database_manager as dbm
import pipelines.bm25.build_bm25_index as bbi
from pipelines.base import Retriever
from pipelines.bm25.tokenizer import tokenize


class P2BM25Retriever(Retriever):
    def __init__(self, storage_root: Path | None = None, db_path: str = bbi.DB_PATH):
        if storage_root is None:
            storage_root = bbi.STORAGE_ROOT
        self._storage_root = storage_root
        self._db_path = db_path

    def retrieve(self, query_text: str, document_id: str, k: int) -> list[NodeWithScore]:
        index_path = bbi._index_path(document_id, self._storage_root)
        if not index_path.exists():
            raise FileNotFoundError(
                f"No BM25 index found for document_id={document_id!r} at "
                f"{index_path}. Run build_bm25_index.py for this filing "
                "before querying it."
            )
        with open(index_path, "rb") as f:
            payload = pickle.load(f)
        node_ids: list[str] = payload["node_ids"]
        bm25 = payload["bm25"]

        tokenized_query = tokenize(query_text)
        scores = bm25.get_scores(tokenized_query)

        ranked = sorted(
            zip(scores, range(len(node_ids)), node_ids),
            key=lambda item: (-item[0], item[1]),
        )[:k]

        nodes = asyncio.run(dbm.get_nodes_by_document(self._db_path, document_id))
        nodes_by_id = {node["node_id"]: node for node in nodes}

        results = []
        for score, _, node_id in ranked:
            row = nodes_by_id[node_id]
            text_node = TextNode(
                id_=row["node_id"],
                text=row["content"],
                metadata={
                    "document_id": row["document_id"],
                    "parent_item_header": row["parent_item_header"],
                    "node_type": row["node_type"],
                    "source_page_num": row["source_page_num"],
                },
            )
            results.append(NodeWithScore(node=text_node, score=float(score)))
        return results
```
